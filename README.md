# AutoTyper (Android, Kotlin)

Вводит текст в любое поле через службу специальных возможностей. Без root.

## Возможности
- Обычный режим: весь текст в поле, опционально автоотправка.
- Режим «Сообщения»: запятая или новая строка делят текст на сообщения, каждое отправляется отдельно.
- Загрузка `.txt` (UTF-8, UTF-16 с BOM, Windows-1251).
- Спец. клавиши в тексте: `{ENTER}`, `{BACK}`, `{SEND}`, `{WAIT:500}`.
- Поиск кнопки отправки: по словам (send, отправить и т.п.), справа от поля, затем Enter.
- Макросы: запись тапов, свайпов, пауз, «Назад», «Домой», текста; запуск из меню с повторами.
- Красная кнопка «СТОП» поверх экрана останавливает всё.

## Сборка
GitHub → Actions → Build APK → Run workflow. Готовый `app-debug.apk` в Artifacts.

## Установка и включение
1. Установи APK. Удали старую версию, если была.
2. Настройки → Специальные возможности → AutoTyper → включи.
3. Android 13+: если переключатель серый, Настройки → Приложения → AutoTyper → ⋮ → «Разрешить ограниченные настройки».

## Ограничения
- Поля паролей, банковские приложения и некоторые игры блокируют ввод и имитацию касаний.
- Во время записи макроса касания не доходят до приложения под слоем записи.
